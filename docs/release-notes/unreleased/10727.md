# Technical and Architectural Updates

## Code Health

* The [`Future` and `Promise` types have been
  moved](https://github.com/lightningnetwork/lnd/pull/10727) from the `actor`
  package into the `fn` package, where they belong as general-purpose async
  primitives. Callers of `actor.Future[T]`, `actor.Promise[T]`,
  `actor.NewPromise[T]`, `actor.CompleteWith` and `actor.AwaitFuture` should
  use the `fn/v2` equivalents.
