# Improvements

## Breaking Changes

* `lncli encryptdebugpackage` now compresses debug packages with gzip instead
  of Brotli. New `lncli` binaries can't decrypt debug packages produced by
  older binaries; use the matching older `lncli` to decrypt those
  [packages](https://github.com/lightningnetwork/lnd/pull/10836).

# Technical and Architectural Updates

## Testing

* Postgres test fixtures now require the `test_db_postgres` build
  [tag](https://github.com/lightningnetwork/lnd/pull/10836), so default builds
  no longer compile the Docker SDK dependency tree.

## Code Health

* Builds now use read-only module files and the locally installed Go
  toolchain, and CI verifies the module cache. Several small dependencies used
  by message signing, aezeed, systemd notifications, NAT-PMP, and legacy
  invoice migrations have moved into the tree or been replaced with
  standard-library [code](https://github.com/lightningnetwork/lnd/pull/10836).
