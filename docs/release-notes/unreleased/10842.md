# Bug Fixes

* The sweeper [isolates rejected inputs](https://github.com/lightningnetwork/lnd/pull/10842)
  with diagnostic transactions that are never broadcast. Valid batch inputs
  remain retryable after isolating an invalid input or backend-reported mempool
  conflict. Inconclusive RBF fee checks remain retryable at the fee cap, and
  survivors keep their requested starting rates. Rejected replacements retain
  monitoring of the accepted transaction; terminal results release its monitor.
