# Bug Fixes

* The `DescribeGraph` RPC response cache (enabled via
  `caches.rpc-graph-cache-duration`) is now only used for requests that set
  neither `include_unannounced` nor `include_auth_proof`. Previously a single
  cached response was returned regardless of those fields, so a caller could
  receive unannounced channels or auth proofs it did not ask for, or miss ones
  it did
  ([#11115](https://github.com/lightningnetwork/lnd/issues/11115)).
