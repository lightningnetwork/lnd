# Bug Fixes

* Fixed onion-message forwarding when the next hop is a [local
  alias](https://github.com/lightningnetwork/lnd/pull/11245). That alias is
  not in the graph, so the forward was dropped with `edge not found`. The
  resolver now uses the switch's forwarding indexes for a local alias. As
  BOLT 4 requires, a next-hop SCID now resolves only for an announced channel
  or a local alias. Before this change, the confirmed SCID of a private
  channel resolved through the graph. It no longer resolves.
