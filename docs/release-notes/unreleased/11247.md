# Bug Fixes

* Fixed a restart ordering bug that could leave a force-closed channel stuck in
  `waiting_close_channels`, or a funded channel stuck in
  `pending_open_channels`, after the transaction had reached the required
  confirmation depth. The bug could occur when subscriptions for the same
  transaction or outpoint supplied different height hints. A later
  subscription with an earlier hint now scans the range the existing scan
  skipped, and cached hints record the range their scans covered.

  A node that was already [affected before
  upgrading](https://github.com/lightningnetwork/lnd/issues/11182) can retain a
  legacy cached hint without this coverage information. If the channel remains
  stuck after upgrading, restart `lnd` once with
  `--height-hint-cache-query-disable`, wait for the channel to recover, and
  then remove the option to restore normal rescan performance. See
  [PR #11247](https://github.com/lightningnetwork/lnd/pull/11247) for details.
