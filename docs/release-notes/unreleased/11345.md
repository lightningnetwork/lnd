# Bug Fixes

* [Fixed a bug](https://github.com/lightningnetwork/lnd/pull/11345) where a
  `shutdown` message whose delivery script was longer than 34 bytes failed to
  decode, which disconnected the peer. `option_shutdown_anysegwit` allows
  witness programs of up to 42 bytes, which lnd already accepted at channel
  open and when validating the script, so the wire limit now matches.
