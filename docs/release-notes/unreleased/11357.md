# Technical and Architectural Updates

## BOLT Spec Updates

* The BOLT 11 invoice decoder now [rejects invoices that the spec marks
  invalid](https://github.com/lightningnetwork/lnd/pull/11357) but were
  previously accepted: fixed-length fields (`p`, `h`, `s`, `n`) with the wrong
  length, more than one payment address (`s`) field, and a high-S signature on
  an invoice with an explicit destination (`n`) field. The spec's invoice test
  vectors are now part of the test suite.
