# Technical and Architectural Updates

## BOLT 12 (Offers)

* [BOLT 12 offer creation and invoice request
  dispatch](https://github.com/lightningnetwork/lnd/pull/11374): add the
  `CreateOffer` RPC to the `devrpc` sub-server, with the
  `POST /v2/dev/createoffer` REST route and the `lncli createoffer` command,
  which create and store an offer. Like the rest of `devrpc`, they exist only
  in a `dev` build. The node now sends each invoice request that it receives
  to the BOLT 12 handler and sends the invoice over the reply path of the
  request. A failed request gets no `invoice_error` reply yet.
