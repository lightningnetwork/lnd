# Improvements

## Performance Improvements

* The chain notifier [no longer waits on database write
  batching](https://github.com/lightningnetwork/lnd/pull/11385) when
  committing height hints on the bolt backend. This removes 10-20ms of
  latency from every block it processes, and 10ms per watched outpoint per
  scanned block from neutrino spend rescans.
