# Bug Fixes

* PSBT inputs that carry no sighash type are now [signed with
  SIGHASH_ALL](https://github.com/lightningnetwork/lnd/pull/11387) as BIP 174
  prescribes, rather than with hash type zero. Hash type zero is only
  meaningful for taproot, so a SegWit v0 signature tagged with it was rejected
  by standardness rules and the transaction could not be relayed. Both the
  local and the remote signer are affected; taproot inputs continue to treat
  zero as SIGHASH_DEFAULT.
