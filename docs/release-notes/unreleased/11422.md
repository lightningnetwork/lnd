# Improvements

## Breaking Changes

* lnd [no longer opens or accepts](https://github.com/lightningnetwork/lnd/pull/11422)
  new channels that use the static remote key commitment type. Explicit RPC
  requests and peer proposals are rejected, and automatic negotiation now
  requires both peers to support anchor channels.

  Existing static remote key and legacy channels are unaffected. They remain
  operable and report their original commitment type through the RPC. The
  `STATIC_REMOTE_KEY` enum value remains for this reporting, while the
  `--tweakless` option has been removed from `lncli openchannel`.

## Deprecations

* The `protocol.no-anchors` configuration option is deprecated and no longer
  has any effect. New channels require anchor support.
