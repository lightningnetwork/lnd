# Improvements

## Performance Improvements

* The neutrino backend now uses the new neutrino sync and storage stack
  ([#11429](https://github.com/lightningnetwork/lnd/pull/11429)). Block and
  filter headers sync in parallel across peers, through a unified query layer.
  Headers can be kept in a SQL store. An existing bbolt `neutrino.db` is
  imported into that store automatically on first start.
