# Technical and Architectural Updates

## Code Health

* The `actor` module gains [non-blocking and shutdown-safe
  primitives](https://github.com/lightningnetwork/lnd/pull/11431). `TryTell`
  and `TryAsk` never block from any goroutine and report `ErrMailboxFull`,
  `ErrMailboxClosed` or `ErrActorTerminated` instead of waiting for room.
  `Tell` and `Ask` made with the context of a receive turn no longer park on a
  full mailbox: they spill into a bounded overflow queue, configurable with
  `ActorConfig.MailboxOverflowLimit`, and fail with `ErrMailboxOverflow` at the
  cap. A blocking `Send` from outside the actor now waits for that overflow to
  drain so it can't overtake accepted messages. `AskThen` delivers an `Ask`
  reply to the caller as a later message, and `Actor.Done`,
  `Actor.StopAndWait` and `ActorSystem.ShutdownAndWait` let an owner wait for
  the last `Receive` to return before closing resources. The `actor` module
  now requires `lnd/queue` v1.2.1.
