# New Features

## Functional Enhancements

* A new `internal-address-type` option
  ([#11433](https://github.com/lightningnetwork/lnd/pull/11433)) sets the
  address type the wallet uses to pay itself: the change of `SendCoins`,
  `SendMany` and channel funding transactions, the sweeps after a channel
  close, the cooperative close delivery address and the watchtower reward
  address. The default `p2tr` keeps today's behavior. With `p2wkh` the wallet
  never creates P2TR outputs for itself, which lets lnd run in watch-only mode
  with a remote signer that can only produce ECDSA signatures.
