# Bug Fixes

* Forwarding fee calculations now [reject amounts and policies that
  overflow](https://github.com/lightningnetwork/lnd/pull/11444), instead of
  wrapping intermediate products or signed inbound totals. Routing and
  pathfinding skip policies whose fees can't be represented, and the HTLC
  switch rejects such a forward through the existing fee-insufficient failure.
  Building a route with `BuildRoute` now returns a fee overflow error for this
  case instead of reporting a missing channel.

# Improvements

## Breaking Changes

* The `ComputeFee` methods of `models.ChannelEdgePolicy` and
  `models.CachedEdgePolicy`, and `models.InboundFee.CalcFee`, now return an
  error when the fee can't be represented. Go packages that import these
  methods need to handle the extra return value.
