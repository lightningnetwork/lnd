# Bug Fixes

* Sweep retries [no longer raise an input's requested starting
  fee](https://github.com/lightningnetwork/lnd/pull/11459) after a failed
  attempt. Inputs retain their fee schedule's original time origin across
  retries and regrouping, while publication history remains separate from
  requested policy. In a batch, each input's elapsed urgency commits only its
  own share of the batch's budget. Constant-rate schedules can publish
  immediately, including when the requested starting rate meets or exceeds the
  budget's maximum.
