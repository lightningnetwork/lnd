# New Features

## RPC Additions

* `SendCoins` gained a `dry_run` field
  ([#11466](https://github.com/lightningnetwork/lnd/pull/11466)). When set, the
  transaction is crafted and checked against the wallet reserve but not
  broadcast, and the unsigned raw transaction and its fee are returned in the
  new `raw_tx` and `fee_sat` response fields.

## lncli Additions

* `lncli sendcoins` gained a `--dry_run` flag
  ([#11466](https://github.com/lightningnetwork/lnd/pull/11466)) to preview a
  transaction and its fee without broadcasting it.
