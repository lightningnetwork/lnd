# Improvements

## Breaking Changes

* The `etcd` database backend is
  [disabled in v0.22](https://github.com/lightningnetwork/lnd/pull/11487),
  superseding the earlier announcement of deprecation after v0.22. Nodes using
  `db.backend=etcd` now refuse to start before database initialization. Etcd
  remains supported for leader election. This change does not migrate existing
  data, and changing `db.backend` does not transfer existing node state.
