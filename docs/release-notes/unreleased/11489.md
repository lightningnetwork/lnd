# Technical and Architectural Updates

## Tooling and Documentation

* CI is [split into three
  tiers](https://github.com/lightningnetwork/lnd/pull/11489): pull requests
  only run the fast checks, the merge queue runs the full unit test matrix,
  the basic itests and the key database itests, and a new nightly workflow
  runs the complete set on master, including the Windows and macOS itests and
  the coverage report. The `full-ci` label runs the merge queue tier on a pull
  request.
