# Technical and Architectural Updates

## Tooling and Documentation

* CI now [points Go's temporary build
  directory](https://github.com/lightningnetwork/lnd/pull/11499) at the
  runner's disk instead of `/tmp`, which is a small RAM backed tmpfs on the
  `ubuntu-26.04` runner image. Large builds such as the per-commit unit test
  check no longer fail with "disk quota exceeded" there.
