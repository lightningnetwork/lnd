# Technical and Architectural Updates

## Tooling and Documentation

* CI [no longer occupies runners for jobs that don't run on a pull
  request](https://github.com/lightningnetwork/lnd/pull/11501): the unit test,
  basic itest, cross compilation and pinned dependency jobs are now skipped
  entirely when they aren't part of the pull request tier, when CI is held and
  for documentation-only changes. `CI result` is the only required status
  check.
