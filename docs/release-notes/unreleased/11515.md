# Bug Fixes

* [The sweeper now tries to publish a sweep at the maximum fee rate its budget
  allows right away](https://github.com/lightningnetwork/lnd/pull/11515) if the
  budget can't pay more than the fee estimate for the sweep's deadline. It used
  to fail to start fee bumping in that case and retry in every block, so the
  sweep wasn't attempted until its deadline was one block away. When the fee
  function is initialized, a starting fee rate above the maximum the budget
  allows, for example a fee rate passed to `lncli wallet bumpfee` that is above
  `sweeper.maxfeerate`, is now capped at that maximum, instead of failing the
  budget check or exceeding `sweeper.maxfeerate`.
