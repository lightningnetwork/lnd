# Improvements

## RPC Updates

* `UpdateChannelPolicy` [can now update individual
  fields](https://github.com/lightningnetwork/lnd/pull/11528). With the new
  `partial_update` flag, `base_fee_msat` and `fee_rate`/`fee_rate_ppm` are
  only applied when marked with `base_fee_msat_specified` or
  `fee_rate_specified`, and `time_lock_delta` only when non-zero. All other
  fields keep their current value. Requests without `partial_update` behave
  as before.

## lncli Updates

* `lncli updatechanpolicy` [no longer requires `base_fee_msat`, `fee_rate` and
  `time_lock_delta` on every
  call](https://github.com/lightningnetwork/lnd/pull/11528). Fields that aren't
  passed keep their current value, and the help no longer shows a misleading
  `(default: 0)`. Against an older lnd, lncli refuses an update that leaves
  out a fee field instead of letting lnd reset it to 0.
