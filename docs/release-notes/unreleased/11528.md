# Improvements

## RPC Updates

* `UpdateChannelPolicy` [can now update individual
  fields](https://github.com/lightningnetwork/lnd/pull/11528). If the new
  `partial_update` message is set, `base_fee_msat`, `fee_rate`/`fee_rate_ppm`
  and `time_lock_delta` are only applied when marked in it, and an unmarked
  field keeps its current value. Requests without `partial_update` behave as
  before.

## lncli Updates

* `lncli updatechanpolicy` [no longer requires `base_fee_msat`, `fee_rate` and
  `time_lock_delta` on every
  call](https://github.com/lightningnetwork/lnd/pull/11528). Fields that aren't
  passed keep their current value, and the help no longer shows a misleading
  `(default: 0)`. Individual fields are set with the flags. Positional
  arguments are only accepted when `base_fee_msat`, `fee_rate` and
  `time_lock_delta` are all set, and an argument left over after the policy
  values and one channel point is now an error. Against an older lnd, lncli
  refuses an update that leaves out a fee field instead of letting lnd reset
  it to 0.
