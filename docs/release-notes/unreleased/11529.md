# Improvements

## Functional Updates

* [Remote signing](https://github.com/lightningnetwork/lnd/pull/11529) verifies
  connection-bound registration, bounds concurrent signing work, and applies
  the recovery guard during startup.

## RPC Updates

* [StopDaemon](https://github.com/lightningnetwork/lnd/pull/11529) returns
  `FailedPrecondition` while wallet recovery is in progress.

## Breaking Changes

* The experimental
  [signer-initiated transport](https://github.com/lightningnetwork/lnd/pull/11529)
  requires connection-bound TLS registration proofs. Upgrade both endpoints
  together.
