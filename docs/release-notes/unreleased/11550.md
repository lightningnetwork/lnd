# New Features

## lncli Additions

* `lncli wallet leaseoutput` gained a [`--no_expiry`
  flag](https://github.com/lightningnetwork/lnd/pull/11550) to lease an
  output without a timeout, and `lncli wallet psbt fund` and
  `lncli wallet psbt fundtemplate` gained `--lockid`, `--lock_expiry` and
  `--no_expiry` to control the leases on the inputs they select. The lease
  output of `lncli wallet listleases` and of both fund commands now includes
  the `no_expiry` field.
