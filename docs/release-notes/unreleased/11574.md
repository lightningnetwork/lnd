# Technical and Architectural Updates

## Testing

* `TestGossipSyncerSyncTransitions` [no longer asserts an exact
  `FirstTimestamp`](https://github.com/lightningnetwork/lnd/pull/11574)
  for the `GossipTimestampRange` message sent when (re)entering active
  sync. The syncer stamps the message with its own clock, so a
  wall-clock second boundary crossed before the test sampled its
  expectation made the exact comparison flaky. The stamped timestamp is
  now asserted to fall within the test's execution window instead.
