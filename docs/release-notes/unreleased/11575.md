# Bug Fixes

* [RBF cooperative close fee bumps](https://github.com/lightningnetwork/lnd/pull/11575)
  are now buffered inside the `RbfChanCloser` state machine instead of being
  dropped during shutdown or flushing or blocking the peer's `channelManager`
  goroutine while waiting on an in-flight offer. Confirmed RBF closes also now
  tear down the channel's active state and switch link for both local and
  remote-initiated closes.
