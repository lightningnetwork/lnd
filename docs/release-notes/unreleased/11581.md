# Bug Fixes

* A PSBT channel funding flow that uses `skip_finalize` now [keys the channel
  to the TXID of the signed funding
  transaction](https://github.com/lightningnetwork/lnd/pull/11581) when the PSBT
  spends nested SegWit (P2SH-P2WPKH or P2SH-P2WSH) inputs. Signing such an
  input sets its scriptSig, which changes the TXID, so before this fix the
  channel waited for a transaction that was never published
  ([#11570](https://github.com/lightningnetwork/lnd/issues/11570)). With
  `skip_finalize`, inputs whose final scriptSig can't be known before signing,
  such as a nested SegWit input without its redeem script, are now rejected.
