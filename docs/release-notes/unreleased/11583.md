# Technical and Architectural Updates

## Code Health

* The btcd chain notifier now [determines historical spends by scanning the
  chain's blocks](https://github.com/lightningnetwork/lnd/pull/11583) instead
  of issuing the deprecated `rescan` command, as the bitcoind notifier already
  does. Btcd-compatible backends that do not implement `rescan` are now
  supported. A historical spend dispatch now also completes when no spend is
  found, so the spend hint of an unspent output script is committed and the
  dispatch is no longer repeated from the original height hint after every
  restart.
