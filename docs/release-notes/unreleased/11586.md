# Technical and Architectural Updates

## BOLT Spec Updates

* Final simple taproot channel support now [requires the complete feature
  dependency chain](https://github.com/lightningnetwork/lnd/pull/11586):
  `option_simple_taproot` requires `option_simple_close`, which in turn
  requires `option_shutdown_anysegwit`. The dependency chain is enforced for
  local, remote, and custom feature vectors while preserving `lnd`'s existing
  automatic simple-close enablement for final taproot channels.
