# Improvements

## Performance Improvements

* A new opt-in option
  [`db.bolt.mmap-populate`](https://github.com/lightningnetwork/lnd/pull/11591)
  prefaults bolt database files into memory when they are opened on Linux.
  This avoids reading them one page at a time during startup, which is slow on
  storage with a high per-request latency such as network volumes. It is only
  useful if the database files fit into the available memory.
