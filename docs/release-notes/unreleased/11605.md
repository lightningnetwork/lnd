# Bug Fixes

* `lncli wallet pendingsweeps` now [reports the fee
  rate](https://github.com/lightningnetwork/lnd/pull/11605) of the sweeping
  transaction currently in the mempool. Previously `sat_per_vbyte` kept the fee
  rate of the first broadcast and was only refreshed by a manual `bumpfee`, not
  by the sweeper's own RBF replacements.
