# Bug Fixes

* The `zpay32` decoder now [rejects a blinded payment path that ends
  prematurely](https://github.com/lightningnetwork/lnd/pull/11606) instead of
  decoding it with a partly zero-filled cipher text. A truncated first
  blinding point, hop count, blinded node pubkey or cipher text blob used to be
  silently accepted because the byte count returned by the read was discarded.
