# Bug Fixes

* [Fixed a set of bugs](https://github.com/lightningnetwork/lnd/pull/11609)
  that mostly hit nodes running the neutrino backend:
  * A zombie channel whose stale side was `node2` stored the wrong key in the
    zombie index, so `node2`'s fresh updates could never resurrect it, and a
    zombie revived by `FilterKnownChanIDs` was never queried for again.
  * With `AssumeChannelValid`, our own closed channels were never pruned from
    the graph and kept being re-announced. They're now pruned once channeldb
    has a close summary for them.
  * With `tor.skip-proxy-for-clearnet-targets`, clearnet host names (e.g. in
    `neutrino.connect`) are now resolved directly instead of through Tor.
  * The sqlite, postgres and etcd `kvdb` backends now run every `OnCommit`
    callback registered in a transaction, not only the last one.
