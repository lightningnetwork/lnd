# Bug Fixes

* A subscriber to all invoices that supplies an add or settle index no longer
  receives the same settled or added invoice twice when it subscribes while
  that invoice is being added or settled. The subscription now skips [live
  events that are already part of its
  backlog](https://github.com/lightningnetwork/lnd/pull/11629). AMP invoices
  and subscribers that supply only an add index are not covered.
