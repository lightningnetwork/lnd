# Bug Fixes

* [Channel announcement validation](https://github.com/lightningnetwork/lnd/pull/11632)
  rejects node IDs that are out of lexicographic order, as BOLT 7 requires.

* [Funding validates the remote HTLC constraints](https://github.com/lightningnetwork/lnd/pull/11632)
  before accepting a channel. If the configured minimum exceeds the usable
  maximum, lnd caps the advertised minimum and logs both values.

* [Local announcement signatures](https://github.com/lightningnetwork/lnd/pull/11632)
  stay out of the evictable premature-gossip cache, so a restart or cache
  eviction cannot lose them. The cache also accounts for decoded feature-map
  memory when enforcing its limits.

* [Failed and timed-out pending channels](https://github.com/lightningnetwork/lnd/pull/11632)
  release discovery signals, initial forwarding policies, opening state,
  chain-arbitration watches, persistent reconnects, and on-disk backups.
  Funding timeouts also free pending channel slots for offline peers.

# Improvements

## Breaking Changes

* [BOLT text validation](https://github.com/lightningnetwork/lnd/pull/11632)
  rejects disallowed Unicode characters in node aliases, BOLT 11 invoice
  descriptions, and BOLT 12 descriptions, issuers, and payer notes. This
  includes newlines in invoice memos and zero-width joiners used by some
  emoji. lnd cannot pay an invoice with a disallowed description, including
  invoices generated by older lnd versions or other wallets. Ask the recipient
  to reissue the invoice with a compatible description.

  Before upgrading, remove any disallowed characters from your configured
  `alias=` value. An invalid configured alias prevents startup. If you set
  your alias through `peersrpc.UpdateNodeAnnouncement` and it is now invalid,
  lnd logs a warning and uses the default alias derived from the node public
  key.
