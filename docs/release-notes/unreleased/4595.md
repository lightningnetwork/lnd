# New Features

## Functional Enhancements

* The mobile bindings now expose
  [`ServiceStatus`](https://github.com/lightningnetwork/lnd/pull/4595), which
  reports lnd's runtime state through a callback: `1` while starting or running,
  and `0` when stopped. Applications can use it to check whether lnd needs to be
  started and to detect when shutdown has completed after `StopDaemon` returns.
